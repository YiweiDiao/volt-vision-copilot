# Volt Vision Guidance Catalog

This directory contains curated, local, auditable guidance for the Volt Vision Copilot educational prototype.

The files are not industrial maintenance procedures, diagnostic rules, repair instructions, or evidence of machine health. They are conservative prompts for manual review after deterministic cycle screening.

A future agent may retrieve and summarize this material from structured
screening events. The agent must not infer root causes, confirm tool wear, confirm machine failure, or decide that maintenance is necessary.
